# V1.3 展示、后台与数据层分离

首页 `/` 为只读工业显示，`/admin.html` 为配置/控制/历史；页面职责沿用 V1.1/V1.2，V1.3 继续拆开传输与画布。

## 展示入口

DisplayApp 消费展示会话、类别、指标和已配对帧。stream 负责 WS、重连、协议校验、预览取图与解码。DetectionStage 只画已准备的图和框，处理筛选、选择、缩放、全屏和原图坐标事件。

约束：不直接读 Run.model 内部结构来推断引擎；不因某个引擎名称不同而换绘制代码；不向展示WS发送生产控制。图片失败/迟到不得配旧框，新会话到来时旧异步结果作废。

## 后台入口

AdminApp 仍使用管理HTTP创建、暂停、继续、停止任务，以及历史查询和导出。历史Frame经适配层转换后进入同一画布。

约束：实时连接状态与历史可读性分开。历史画面使用历史类别，不能被当前新任务类别污染。allow-download 只在后台路径启用；源文件/模型路径等审计信息不进入通用展示投影。

## 数据语义

frame_key 标识来源帧，stream_session_id 标识当前展示运行。类表随会话，坐标始终原图像素。图中编号帧内唯一，没有跨帧跟踪含义。中心点和角度来自统一投影，图像角度不能替代机械臂姿态。

## 回归要求

实时与历史都要检验图片解码后原子提交、切帧/切任务/筛选清空选择、旧请求失效、对象URL释放、125%缩放与全屏坐标不漂移。独立模拟后端替换只改变端点，不修改前端构建。
