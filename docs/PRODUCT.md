# Factory Demo V1.3 产品需求与功能边界

日期：2026-10-28。产品面向后续现场迭代，本版在本机验证通用展示、文件来源和真实 PyTorch 检测。本文的验收条件不是已执行证明；对应测试证据另行记录。

## 1. 通用检测展示

首页 `/` 为只读工业深蓝大屏，消费版本化展示快照。展示图片、HBB/OBB 四点、类别、置信度、中心点与有效角度，提供类别筛选、指针坐标、缩放、全屏及键盘框选择。

边界约束：

- 不加载模型，不访问相机 SDK，不解释原始模型张量，不读取宿主机任意路径。
- 本版通用范围为二维检测；分割、姿态、3D 不在范围内。
- 类别由后端目录提供，不能硬编码 8 类，也不能假设不同模型同一 class_id 含义相同。
- 只对图片已成功解码且帧身份匹配的结果绘框；空检测成功与错误分别显示。
- 缩放/预览压缩不改变原图像素坐标；源坐标允许出界，画面裁切不改变已保存几何。
- 角度是图像长轴方向，不是机械臂末端姿态；无效角度为空，合法 0° 仍有效。
- 筛选只改变显示，不重新统计生产总量、不影响数据库和推理参数。

## 2. 实时通信与预览

展示 WS 推送 JSON 快照，HTTP 取不可变预览图片。浏览器重连获取当前快照；服务端以有界队列隔离慢浏览器。JPEG 编码由独立预览工作线程执行。

边界约束：

- WS 展示连接只读，不接受 pause/resume/start 等生产控制。
- 最新快照和预览可独立于数据库查询提供，但不因此改变任务的数据库持久化要求。
- 预览缓存有限；迟到 URL 可能过期，应取最新快照，不能配旧图。
- 连接仍开着不代表画面新鲜，应显示最后数据时间与陈旧状态；没有新图片也不必认定网络断线。
- 仅允许展示队列跳过旧包，不把该策略套用到待检测文件或执行数据。
- 不承诺每个浏览器显示每一检测帧，也不把 WS 刷新率当模型吞吐。

## 3. 有限目录与上传

配置内的目录和单图上传保留原有一次性任务流程。任务创建时冻结输入清单，完成后进入终态。上传与文件类型/尺寸约束由服务端验证。

边界约束：只接受配置 source_id，不接受 HTTP 任意本机路径。文件被修改、损坏或不支持时记录明确错误；读取失败不等于未检出。保存原图快照保留历史可追溯性。回放 FPS 是有限任务的调度上限，不保证处理能力。

## 4. 持续落盘来源与模拟拍照

生产路线为相机先写本机磁盘，再由程序读取。inbox 来源持续等待已完成发布的文件；模拟脚本按此协议发布文件和帧信息。

边界约束：

- 临时写入文件不可作为完整输入；完成发布后才摄入，不能仅凭文件名出现推断写完。
- 帧身份包含来源、生产会话与帧号；重启产生新会话；重复通知不能当新拍摄。
- 持续流总帧数为 null，无虚构完成百分比；空目录可等待，不当作有限空目录错误。
- 暂停推理不等于相机停止拍摄；磁盘积压必须另行观察，不能悄悄删待检文件。
- 发布频率、实际接收、实际推理和展示频率分别计量；42fps 模拟输入不等于42fps实推理。
- 真相机文件覆盖、保留期限、清理责任、拍摄时间来源和最终格式仍需现场确认。

## 5. 推理引擎

真实后端使用 YOLOv5-OBB PyTorch CPU FP32，权重为独立 factory_now.pt。引擎通过统一输出契约与展示隔离。

边界约束：OpenVINO/TensorRT 未完成真实适配，必须显示 unavailable/reason。模型一次加载复用，换权重需明确重启/新会话，不默认热替换。权重 8 类与 smoke 数据集 7 类顺序不同，本版不计算 AP/准确率。置信度不等于检测正确率。

## 6. 任务控制

后台 `/admin.html` 负责来源、参数、启停与任务查询。只允许一个活动任务；暂停/停止在帧边界生效。

边界约束：受理控制意图不意味着当前模型调用立即中止。停止后不得再由旧 worker 状态覆盖停止意图。模型失败、数据库提交失败和无目标成功帧必须区分。浏览器关闭不创建或停止生产任务。

## 7. 历史、导出与归档

后台查询 PostgreSQL 中的任务/帧，读取原图快照，生成 JSON/CSV/绘框 PNG。历史显示经独立适配器接同一纯画布。

边界约束：历史不重新推理，数据库不是原图备份；删除 runtime 会破坏图片读取。原图与数据库不是跨介质原子事务，失败必须明确。生产数据库失败后继续运行、补传或丢弃策略尚未决定，本版保留失败停任务行为。内存快照不代替持久化。

## 8. 指标与错误

统计区分成功/失败帧、检测实例、原始处理耗时、图像新鲜度和展示状态。

边界约束：未测量使用 null/未知，不能填 0；有效零值保留。累计检测框数不等于跨帧实物去重数量。四阶段耗时不含全部落盘、SQL、网络、渲染。持续任务P50/P95只统计最近最多1000个成功样本，均值累计；有限任务按本轮样本统计。未接入的机器人、温度、能耗、抓取准确率不显示虚构正常状态。

## 9. 部署与扩展

本版仅 127.0.0.1，本机 PostgreSQL，单进程单 worker。显示与管理可有独立路由，但不据此声称权限系统已完成。

边界约束：不开放公网或局域网监听；未来 LAN 部署前再确定认证、权限、TLS 和 WS 访问策略。独立模拟展示后端仅用于接口验收，不连接数据库和模型。没有机械控制器接入，不产生执行动作。

## 10. 核心验收

同一份前端构建产物接入真实后端和独立协议模拟后端，不改展示源码即可显示；历史页仍可查看、选择、下载。补充验收覆盖旧会话迟到、预览失败、连续流无总量、未知指标、不同类别/尺寸和慢浏览器。真实后端的结果契约验证不代替真实引擎精度/吞吐验证。
