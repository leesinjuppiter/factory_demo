# 网页版阅读手册

直接双击本目录的 `index.html`，或上级目录的 `GUIDE.html`。两者内容相同，链接按各自所在目录生成。正文、5 张内联 SVG 图及既有验收截图嵌入 HTML；只复制其中一个 HTML 也可以阅读正文和图示。

源代码、原始证据、独立图和 Markdown 原稿采用相对链接。需要点击这些附件时，保留完整 `factory_demo` 目录结构。外部官方资料链接需要联网；正文阅读不依赖网络或运行中的后端。

## 阅读功能

- 左侧目录按章节展开；页面内链接直接跳转对应内容。
- Ctrl+K 搜索全文章节。多个关键词用空格分隔；Escape 清空搜索。
- 代码块提供复制按钮；浏览器限制剪贴板时可手动选中复制。
- 流程图在窄屏中局部横向滚动，保持文字大小。
- “打印 / 保存 PDF”调用浏览器打印；本次未单独生成 PDF 文件。

## 内容与图源

11 个章节由项目 README、产品、架构、协议、推理、性能指南、性能分析、历史验收记录、数据流指南、模块分离说明与 V1.2 工业展示说明组成。

`diagrams/` 内的 5 个 HTML 可以单独打开，内联 SVG 即图源。`flow-map.json` 保存节点与有向关系；`../DATA_FLOW_GUIDE.md` 保存图解说明及各步骤输入、输出、代码定位。图示按当前实现绘制，没有把 OpenVINO/TensorRT 或性能建议标成已实现。

## 更新文档后重新生成

在项目根目录执行：

```powershell
& 'C:\Users\13480\miniconda3\envs\yolo_v5_obb\python.exe' -B docs\web_manual\build_manual.py
```

生成器仅处理文档与图示，依赖当前环境已有的 Python Markdown 包；不会加载模型、连接数据库或启动服务。输出 `index.html`、`../GUIDE.html`、独立图、图结构 JSON 与文档来源哈希清单。原有 Markdown 正文保持不变；推理章节网页版对“完整处理耗时”的措辞有显式澄清，见网页页脚。

修改图示时编辑 `build_manual.py` 内对应图的节点、连接与文字，再重新生成。不要只改生成后的 HTML，否则下一次生成会覆盖修改。
