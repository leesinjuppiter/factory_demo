# 阅读手册与图示样式

用户于本轮明确选择沿用 factory_demo 现有风格。此处仅保存本手册的设计说明，不修改全局 diagram-design 配置或其他项目样式。

源：`frontend/src/style.css`。背景 #f2f4f3，正文 #203039，重点青绿 #177b68，浅色填充 #edf5f1。小字号次要文字使用更深的 #52676b，避免直接使用界面原灰色导致对比不足。HTTP 连接使用 #2e5aa8。

字体：本机 Segoe UI / Microsoft YaHei，技术字段 Consolas；无外部字体请求。图示使用 doc-wide 的 1280×720 画布与 presentation 字号级（节点 16px、辅助文字与箭头 12px），以保证中文阅读。窄屏保持画布宽度并局部横向滚动；打印时缩放至页面。

各图按 architecture、flowchart、sequence 类型绘制；没有完全匹配本任务的行为语义模板，直接选用类型。连线使用水平、垂直或圆角直角，图例在底部。总览不展开全部读图与异常分支，这些在细节图、数据表和正文说明。单图不超过 9 个主要节点、12 条消息。

使用 diagram-design 的最简浅色模板结构，生成后执行其 self_check.py，并进行真实浏览器渲染和窄屏检查。HTML 内联 SVG 是图源，不依赖 Mermaid CDN。图示不采用动画。

V1.2 展示应用改为工业深蓝；本阅读手册与图示继续保留上述浅色青绿方案，避免长文阅读和打印受到应用主题影响。
